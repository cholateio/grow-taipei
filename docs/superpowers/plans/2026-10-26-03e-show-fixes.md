# 計畫 3.8 演出層修正（鏡頭跟主線、拿掉白光、不瞬移不重疊）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 玩家看得出「現在在演誰、在哪」：鏡頭跟著主線平移拉近、東西用材質閃白出現、角色一律走路進場不瞬移、站著不重疊、演出中背景安靜、字看得到。

**Architecture:** 不動規則引擎與求解器，不動劇本的故事線。改五個地方：鏡頭多一個 `focus`（平移＋拉近）；`turn.js` 自動在每個事件前插 `focus`、不同物品之間插空拍、回合末回全景；`flash.js` 的 CSS 白圓換成 `blink.js`（零件材質／小人實例顏色閃白 0.15 s）；名冊出場改成「從入口點走到站位」、站位改變一律走、站著也分離、演出中只有焦點格的人做日常；泡泡與 LEVEL UP 字級跟視窗高度。最後逐一修八個劇本的入口點與站位排法，重新驗收節奏（門檻 8–50／倒數 ≤ 22）。

**Tech Stack:** 原生 ES modules、three.js（vendor）、node:test、headless Chromium（`npm run shot`）。

**Spec:** `docs/superpowers/specs/2026-10-25-show-layer-design.md` §13（本計畫的依據，取代 §4.3、§6.4、§7 對應段落）；其餘章節照舊。

分支：從 `main`（`a7ffaca`）開 `show-fixes`。

## Global Constraints

- `src/rules/`、`src/solver/` 不改；`npm run check` 持續通過。
- 走路速度：小人 1.6、老鼠 2.0；電工點燈 2.8（既有裁定）；蒙太奇 ×2。
- 鏡頭：全景距離 19／26／40 不變；`focus` 拉近到全景距離 × 0.6，平移 1 秒 easeInOut；跳過、reduced-motion、RESET 立刻回全景。
- 出現／消失不再有 CSS 白圓（`.flash` 刪除）；零件閃白 0.15 s，同一拍多個零件間隔 0.15 s。
- 名冊成員出場一律走路，入口點離站位 ≥ 1.5 單位；站位改變一律走過去；站著的人彼此 ≥ 0.25。
- 字級：泡泡 `clamp(18px, 2vh, 36px)`、圖框 `clamp(28px, 3vh, 52px)`、LEVEL UP `clamp(26px, 2.4vh, 44px)`（已做）。
- 節奏門檻：每回合 8–50 秒、倒數回合 ≤ 22 秒（`tools/pace.mjs`），seed 21 可重現。
- draw call ≤ 150；`npm test`、`npm run check`、`npm run pace -- --check`、`npm run shot` 全綠。

## Review Focus

1. **跳過發生在鏡頭拉近途中**：鏡頭必須回全景（距離 = 全景距離、target = 島心），不留在半路；下一回合第一個 focus 正常平移。
2. **玩家在演出中拖曳鏡頭**：這回合不再 focus（不搶鏡頭），回合結束回全景；拖曳發生在 focus 平移途中也一樣。
3. **名冊人數變多時入口點被 footprint 擋住或在水裡**（珍奶碼頭、巨蛋門口）：成員要從最近可走點走進來，不能站在水上或原地出現。
4. **同一回合同一格連續兩個事件**（例如老鼠 Lv2 接著老鼠咬鮮奶在鮮奶格）：只在格子換時平移，不來回抖。
5. **颱風登陸回合**（所有人走到門口消失、再出來）：閃白只用在零件，人走進門口是直接消失（不閃）；下一回合開頭 `showAll` 的人從門口「走出來」而不是原地出現。

```js
// people.js
people.flashInstance(w, on)        // on=true 整個實例塗白，false 重畫原色
// 舞台
stage.commit(key)                  // 揭露新零件並 blink.part 它；舊零件 blink 後丟掉（stage 建構時收 blink）
// 拍
B.focus(target | 'home', { zoom })   // kind 'focus'，dur 1.0；instant → ms 0；ctx.rig.grabbed 時不動（回 false）
// 名冊宣告新欄位
home.entry: point | point[]          // 新成員出場的入口點（可走點；陣列依 i 輪流）；沒給就用格子邊緣離站位最遠的可走點
roster.setFocus(cells /* [[q,r],…] | null */)   // 只有家在這些格的成員做日常；null = 全部
// turn.js
buildTurn(...) 自動：每個事件前 B.focus(cellCenterOf(e))（同一格不重複）、不同物品事件之間 B.wait(0.6)、回合末 B.focus('home')
// 劇本可回傳自己的 focus 拍（kind 'focus'），turn.js 看到劇本第一拍是 focus 就不再補預設
```

## 各壞結局的代表順序

（取該結局當標題卡的第一條順序）

- **大停電**（9156 種）：鮮奶 → 晶片 → 燈泡 → 代幣 → 颱風 → 老鼠 → 珍奶 → 棒球
- **捷運淹水**（3360 種）：鮮奶 → 晶片 → 代幣 → 颱風 → 燈泡 → 老鼠 → 珍奶 → 棒球
- **大巨蛋鼠災**（4872 種）：鮮奶 → 晶片 → 燈泡 → 代幣 → 老鼠 → 棒球 → 珍奶 → 颱風
- **矽盾未就緒**（17808 種）：鮮奶 → 晶片 → 燈泡 → 棒球 → 代幣 → 老鼠 → 颱風 → 珍奶
- **颱風擋飛彈**（4032 種）：鮮奶 → 晶片 → 燈泡 → 代幣 → 珍奶 → 棒球 → 老鼠 → 颱風
- **鮮奶過期**（18 種）：鮮奶 → 晶片 → 燈泡 → 代幣 → 棒球 → 老鼠 → 颱風 → 珍奶
- **珍奶糖分超標**（570 種）：晶片 → 燈泡 → 代幣 → 老鼠 → 棒球 → 颱風 → 珍奶 → 鮮奶
- **再接再厲**（502 種）：鮮奶 → 燈泡 → 代幣 → 棒球 → 晶片 → 颱風 → 老鼠 → 珍奶

## 統計

- 結局分佈：矽盾未就緒 17808、大停電 9156、大巨蛋鼠災 4872、颱風擋飛彈 4032、捷運淹水 3360、珍奶糖分超標 570、再接再厲 502、鮮奶過期 18、賽博龐克台北 1、外星人統治台北 1
- MAX 數分佈 0..8：1212 13944 10576 6488 2726 3162 1648 562 2
- 隨機平均 MAX 數：2.36
- 貪婪順序：鮮奶 → 棒球 → 晶片 → 燈泡 → 代幣 → 老鼠 → 珍奶 → 颱風 ⇒ 大巨蛋鼠災（5 個 MAX）
- 晶片未 MAX 到終局的比例：96.1%
- 節奏：正解單回合最多 10 個升級、最多 4 個同時到 MAX、MAX 分散在 3 個回合

## 調參紀錄

1. 第一版每個物品 Lv2 都要「放下後一回合」，最後放的物品永遠升不了 → 0 解。改成依故事邏輯互相依賴的寬鬆版（6288 解）。
2. 收緊器加三條：鮮奶 Lv3 要老鼠未出現、代幣 Lv2 要老鼠 ≤1、颱風 Lv3 要棒球未放 → 剛好 2 解。
3. 兩解只差最後兩步：晶片在老鼠升 Lv4 的那一回合之前（或同回合掃描中先到 3）就收編老鼠。同回合裡物品照固定順序掃描，每輪每個物品最多升一級——晶片最後放時第一輪只到 Lv2，老鼠先升到 Lv4，所以走外星人。
4. 2026-10-25 使用者反映晶片是樞紐（不選晶片幾乎沒東西升級）。拿掉三條晶片依賴：燈泡 Lv3 改看珍奶 ≥2（人龍擠滿路口才裝霓虹）、燈泡 Lv4 改看棒球 ≥3（大巨蛋夜場）、代幣 Lv4 改看老鼠 ≥3（老鼠搭捷運 → 無人駕駛）；珍奶 Lv3 改看晶片 ≥2（工程師加班狂喝）。兩條正解順序沒變，仍剛好 2 解；現在只有珍奶 Lv3 與老鼠分岔看晶片。
5. 2026-10-25 使用者反映前五回合沒東西動、第六回合一次連升一堆，且「放下去就 MAX」很怪。照 GROW 的節奏重做：引擎改成每回合每物品最多升一級、剛放的當回合不升；第 8 個放完後再倒數 2 回合（`CLOSING_TURNS`）。規則改成 Lv2、Lv3 放下後自己長，最後一兩級才看別人，並加入「要趕在 X 之前」的時間窗口：大巨蛋要在捷運通車前蓋、老鼠要趁學校沒蓋好才生一窩、鐘塔要趕在晶片升廠房前、無人駕駛要趕在全島 LED 前。用白名單子句＋兩兩搜尋收到剛好 2 解；平均 MAX 數門檻放寬到 3.5。
6. 2026-10-25 改成 41 級（max 6/6/5/6/3/5/4/6，使用者決定）。倒數 2 回合時算式沒有空間：四個 max 6 必須佔前 5 回合、老鼠和燈泡 ≤ 6，颱風被迫最後放、永遠不會停在 Lv2（颱風擋飛彈到不了）→ 倒數改成 3 回合。「颱風賴著不走」的門檻從「有球場」改成「有大巨蛋（棒球 ≥3）」（棒球現在必須早放）。節奏驗收改成「同一回合到 MAX ≤ 3 個、MAX 分散 ≥ 4 個回合」（原本「每回合升級 ≤ 4」和每回合自己長的節奏互相矛盾）。白名單收不到兩解，改用全候選兩兩搜尋（`tools/pairsearch.mjs`、隨手腳本），挑有故事的一條：老鼠 Lv2 要趁亂生一窩——學校、看台蓋好有人打掃，颱風過後大掃除也生不出來。鮮奶過期改成「放了六回合還沒蓋鐘塔」。工具：`tools/relax.mjs`（找瓶頸）、`tools/try.mjs`（試算覆寫）、`tools/pairsearch.mjs`（白名單組合搜尋）、`npm run solutions`（重產本檔）。
7. 2026-10-28 選擇帶動升級（計畫 5b，設計 `specs/2026-10-28-choice-growth-design.md`）：拿掉倒數三回合，`CLOSING_TURNS` 3 → 1；放下的物品當回合就長、每級都有預設跳級 `up[n−1] ∧ up[n]`（鮮奶 steady 除外）。只改這三條是 24 條全 MAX，先放寬三條（鮮奶 jump[7] 拿掉晶片、燈泡 up[7] 代幣 6、up[8] 晶片 4）、收緊三條（晶片 up[3] 燈泡 ≥6、鮮奶 up[3] 有棒球、鮮奶 up[10] 颱風 ≤1），颱風登陸的大停電／淹水門檻 ≤2 → ≤4，回到剛好 2 解；第 7 個一定是老鼠、第 8 個一定是颱風，賽博／外星改成第 3 個先放燈泡還是代幣。燈泡 jump[5]、珍奶 jump[3] 留著但不會發生。

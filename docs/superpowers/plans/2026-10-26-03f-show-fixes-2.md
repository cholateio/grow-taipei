# 計畫 3.9 演出層第二輪修正（過橋、穿牆、蓋房子、人分散、全景跟 101）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用者第二段錄影的五個根本問題：人過橋下半身被切、人穿牆、蓋房子看不到也不像在蓋、人都擠在三格、最後大升級沒回全景且 101 頂端出框。

**Architecture:** 不碰規則引擎與求解器，不換建築模型。走路格（`nav.js`）的橋面高度改成跟橋幾何一致、footprint 外擴；小人（`people.js`）多一個 `build` 動作與工具零件；錨點多一個 `frontOf`；名冊宣告（landmarks／boba／baseball／satellites 的 view）重排人數與家；鏡頭多 `setSkyline`，101 升級的劇本改成在全景裡演。

**Tech Stack:** 原生 ES modules、three.js（vendor）、node:test、headless Chromium（`npm run shot`）。

**Spec:** `docs/superpowers/specs/2026-10-25-show-layer-design.md` §14（本計畫依據）；§13 的裁定照舊。

分支：從 `main`（`e9269d2`）開 `show-fixes-2`。

## Global Constraints

- `src/rules/`、`src/solver/` 不改；建築模型（compound parts）不改外形；`npm run check` 持續通過。
- 走路速度：小人 1.6、老鼠 2.0；閒晃 0.5；站著分離 0.25；入口離站位 ≥ 1.5。
- 橋面：`groundY` 與橋幾何（`base + sin(π·s/len)·0.08 + 0.025`）差 ≤ 0.01；footprint 外擴 `PAD = 0.12`。
- `build` 動作 1.6 秒；`frontOf(at, r)` 往 `OVERVIEW_DIR` 的 xz 方向。
- 島民 5（含 2 位溫泉客）、珍奶人龍 ≤ 6、棒球觀眾站 4 晃 2、燈塔守塔人 1（燈泡 ≥2）。
- 全景：101 頂端在 16:9（1.78）與 21:9（2.37）都落在畫面上緣 10% 以內（NDC y ≤ 0.8），島心仍在畫面內。
- 節奏門檻不變：每回合 8–50 秒、倒數 ≤ 22（`node tools/pace.mjs --check`，seed 21）；draw call ≤ 150；`npm test`、`npm run check`、`npm run shot` 全綠。

## Review Focus

1. **高低格之間的階梯**：`groundY` 仍是直線內插，人走階梯不浮不陷（Task 1 測試涵蓋每座橋／階梯）。
2. **footprint 外擴後原本剛好可走的窄道**（101 與吊車之間、夜市攤位之間、學校圍牆邊）：A* 仍找得到路，沒有人被困在孤島格（Task 1：兩條正解 live 演完沒有成員卡住）。
3. **`frontOf` 落在水裡或別的 footprint 裡**（巨蛋靠鏡頭側就是橋頭）：取最近可走點，且仍在 r ± 0.5 內（Task 2 測試）。
4. **溫泉客與老鼠泡溫泉同時在池邊**（老鼠 ≥3 且代幣 <2）：不重疊（分離 0.25），溫泉客不站進池子（Task 3）。
5. **101 升級發生在倒數回合（蒙太奇）**：回全景的拍要留在 `MONTAGE_KEEP`，而且 `setSkyline` 在跳過時也更新（Task 4：montage 與 skip 各一個測試）。

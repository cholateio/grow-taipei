# 手機重玩迴圈與跳過鍵 實作計畫（計畫 12）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 朋友第一次在手機上打開連結，玩完一局發現沒有全 MAX 就直接再玩；演出可以用一顆看得見的「跳過」鍵跳過；專案可以部署到 GitHub Pages。

**Architecture:** 跳過鍵＝`src/ui/cards.js` 頂欄多一顆按鈕，`src/app.js` 的每幀迴圈照 `show.skippable` 顯示／隱藏，取代畫布的 click 跳過；重玩＝終局之後頂欄 RESET 變醒目（純樣式、沒有文字）；部署＝`.github/workflows/pages.yml` 把 repo 根目錄當靜態站發布、`index.html` 補 OG／description；載入＝量開局真的抓了哪些 glb、把純點綴的模型延後到第一幀之後。

**Tech Stack:** 原生 ES modules、three.js（vendor）、`node --test`、`test/helpers/fakedom.js`、GitHub Actions `actions/deploy-pages`。

**Spec:** 使用者 2026-11-01 的一句話需求（本檔 §設計）；上位設計 `docs/superpowers/specs/2026-10-24-grow-taipei-design.md` §9（手機）、§8.5（分享的 OG tags）；結局卡已拿掉（2026-11-01），圖鑑／分享圖不做（使用者：不給文字描述）。

## 設計（決定好的事）

1. **跳過鍵**：頂欄 `.tools` 最左多一顆 `button[data-act=skip]`「跳過」，只在 `show.skippable`（時間軸忙著、而且不在終局前的 hold）時顯示（`hidden` 屬性），按下呼叫 `show.skip()`。`src/show/index.js` 加 `get skippable()`。畫布的 `click → skip` 監聽拿掉（拖鏡頭的 pointerdown 照舊）。手機上按鈕最小 44 px 高；顯示與隱藏不做動畫。
2. **重玩迴圈**：遊戲結束（`game.finished`）後頂欄 RESET 加 `class="glow"`（珊瑚底白字、每 1.6 s 輕輕放大一次 1 → 1.06；`prefers-reduced-motion` 時不動）；RESET 後拿掉。物品列照舊顯示 Lv.n／MAX（黃）——玩家自己看出沒全 MAX。沒有任何新文字。
3. **部署**：`.github/workflows/pages.yml`（push 到 main 就 `actions/upload-pages-artifact` 整個 repo 根目錄、`actions/deploy-pages`；排除 `shots/`、`grow_prototype/`、`docs/`、`test/`、`tools/`、`.superpowers/` 用 `.pagesignore`？——GitHub Pages 沒有 ignore 檔：改成 workflow 裡先 `rsync` 出 `dist/`（index.html、src、vendor、assets）再上傳）。`index.html` 補 `<meta name="description">`、`og:title`／`og:description`／`og:image`（圖先用 `shots/wide-end.png` 複製到 `assets/og.png`，1280 寬）。`README.md` 寫部署方式與本機開發方式。**不建 remote、不 push**（協調者在最後問使用者要不要開 GitHub repo）。
4. **開局載入**：寫一支 `tools/startup-bytes.mjs`：無頭開局（`headlessShow`，lv 全 0）記 `assets.spawn` 被要求的 glb 路徑，加上 `src/app.js` 開局直接 spawn 的點綴（柴犬），算檔案大小總和並印表；三 JS（three.module.js 1.3 MB 會被 Pages gzip）另列。柴犬（528 KB）改成島建好、第一幀畫出來之後才 spawn（`requestIdleCallback` 或 `setTimeout 0`），不擋開局。目標：開局 glb ≤ 1.5 MB（量到超過就在報告列出最大的三個、不硬砍）。

## Global Constraints
- 規則層（`src/rules/*`）不動；`npm run check` 仍剛好一解；`npm run pace -- --check` 輸出不變（這批不碰演出）。

- 截圖預算 ≤ 250／手機 ≤ 150（`npm run shot`）；跳過鍵在 `?auto` 截圖裡不該出現（瞬間套用時不忙）。

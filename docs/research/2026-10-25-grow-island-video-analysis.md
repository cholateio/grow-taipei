## 2. 從影片看到的原則

1. **回合越後面越長**：10、17、21、25、39、58、25、46 秒，平均約 30 秒。長度來自島上「會動的東西」越來越多，每個新物品都要讓舊角色去互動一輪。我們現在一回合約 8 秒，而且每回合差不多長。
2. **幾乎每個變化都是一段「旅程」**：角色走到某處 → 做一件事 → 結果在它停下的地方出現 → 走回去。土路是工人一邊走一邊挖出來的（6 秒長成一圈）；河是村民上山之後才流下來；山洞是機器人走到懸崖揮劍砍的；藥水是火箭飛到月球抓回來的。東西不會憑空從地上彈出來。
3. **升級的對象常常不是剛放的物品**：放方向盤 → 機器人升級、村民談戀愛、房子升兩級；放紅罐 → 房子升、機器人升、坑裡生出小車。放下去的物品本身往往只是「觸發器」，演出都在其他角色身上。
4. **一次升級可以連鎖兩三步，每一步各有自己的 LEVEL UP**：房子 73 s、75 s、77 s 連升三次，每次之間隔 2 秒，之間有村民走動。
5. **情緒符號代替文字**：「……」對話框（思考、等待）、紅色虛線（我在看誰／我要去哪）、愛心（互動成功）、倒數 3-2-1（發射）。觀眾不用讀字就知道因果。
6. **新東西出現的方式**：出現處先白光一閃（0.25–0.5 秒），然後東西「在那裡」了，沒有縮放彈跳。LEVEL UP 黃字在頭上停約 1 秒。
7. **每次升級都留下一個會動的東西**：繞圈的小車、跳動的史萊姆、繞島的船、走路的村民、火山煙。到後期畫面上同時有 5–6 個東西在動，但每次只有一個「主角」在演當前事件，其他是背景。
8. **鏡頭只在一次大事件移動**：火箭上太空那段鏡頭往上平移、回來。其餘全程固定。
9. **物品列只變灰，過程中不顯示 Lv**：等級只在結局時用「Lv MAX」一次亮出。
10. **放置本身很輕**：點了之後約 1 秒，物品就在定位出現；重的是接下來誰過來跟它互動。

## 3. 我們現在的做法和影片的差距

| 影片 | 我們 |

| 升級演在其他角色身上 | 每個物品各自管自己那格 |
| 一回合 10–60 秒，越後面越長 | 每回合約 8 秒 |
| 情緒符號（……、虛線、愛心、倒數） | 只有 Lv.n 飄字 |
| 每次升級留下一個會動的東西 | 多數升級是靜態零件 |

## 4. GROW Cube（183 秒）與 GROW Valley（757 秒）的補充觀察

### GROW Cube
- 一個方塊、十個面板，每個物品放下後只有「一個小人在做一件事」：挖水道、搬水、種樹、蓋階梯。鏡頭不動，小人沿著方塊的稜線走。
- **每次升級都改變地形**：水從頂端流下來變成瀑布、樹長成大樹蓋住方塊、底下挖出洞穴。放物品的「結果」永遠是地形變了，不是原地換模型。
- LEVEL UP 字停 1 秒；一回合 10–25 秒；全程有 3–5 個東西在動（水流、小人、動物）。
- 結局：CONGRATULATIONS 直條字、每格亮「Lv.MAX」。

### GROW Valley
- 和我們最像：固定俯視、一塊地、小人在地形上走動。**每個物品 = 一個有身分的小人**（工程師、研究員、礦工、醫生……），放下去就是「這個人來了」，升級就是「這個人去做了什麼」。
- **回合 = 小人走到某處做事，結果留在那裡**：礦工挖出一條環形土路（10 秒）→ 後面的人把它鋪成石路 → 再後面變成鐵軌，火車繞圈。研究員走去河邊 → 水泥廠出現 → 之後河被改道成運河。每個物品都讓前一個留下的東西再升一級。
- **情緒泡泡是主要語言**：白色方框裡畫圖（放大鏡、顯微鏡、樹、鯨魚、兩個人握手），不是文字。角色一邊走一邊冒「……」，到定點冒「♥」或「！」。鏡頭不動，泡泡就是讓你知道「他在想什麼」。
- **鏡頭只在三種時候切**：地底（挖礦、鍛造，平移到地下剖面）、太空（火箭）、特寫（研究室）。切換用整畫面平移，不是縮放。
- 回合長度 20–60 秒，越後面越長。第二局（Ancient Bonus）是另一條劇情線，證明同一批角色可以演完全不同的故事。

### 跨三款共通的規則（設計演出層時照這個）
1. 一回合一條主線，一個主角。
2. 主角走到定點，結果在那裡出現；走路的時間就是「等待」的節奏，不另外停頓。
3. 新東西出現用白光／直接出現，不縮放。
4. 情緒泡泡：「！」注意到、「……」思考或等待、「♥」互動成功、方框畫圖 = 「他想要什麼」。
5. LEVEL UP 字停約 1 秒，只標在被升級的東西頭上，物品列只變灰。
6. 每次升級留下一個會動的東西（走動的人、繞圈的車、流動的水）。
7. 鏡頭只在「換場景」時平移（地底、太空），其餘固定。

## 5. 我們的老鼠試作（30 秒錄影）看到的問題

- 主線是對的：一隻老鼠出窩 → 鮮奶 → 中央 → 捷運站 → 跳上車，看得出它在幹嘛，泡泡（！、♥、……）有用。
- **穿牆**：老鼠直線穿過大巨蛋、101、小學校舍。走路路線只算「格到格」，沒有避開建築。
- **列車上的老鼠重疊**：五隻疊在三節車廂上，看起來像一坨。
- **LEVEL UP 太小**：在 1280 寬的畫面上只有幾個像素高，而且顏色和背景同色系。
- **同時發生的事太多**：老鼠跑的時候，晶片園區、捷運站、巨蛋在不同角落閃，眼睛跟不過去。GROW 的做法是「主角走過去的時候才變」。
- 老鼠放大後比例還可以，正式版要和小人一起定尺寸。

# 計畫 3：演員（八物品本體、衍生角色、跨物品反應、101、火山與溫泉）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把計畫 2 的方塊佔位角色換成真正的演員：八個物品每一級的本體、它們生出的小人／老鼠／列車、物品之間的互相影響、反映全島進度的 101，以及北側台地的陽明山（火山）與北投溫泉；順便把主島放大 1.25 倍，讓這些東西放得下。

**Architecture:** 演員層是一個「純函數 view + 差異套用」的舞台：每個物品模組輸出 `view(lv, flags) → { partKey: partSpec }`（純資料，Node 可測），舞台（`stage.js`）把前後兩份 view 做差異，變了的零件用 GROW 式「縮小→煙霧→彈出」換掉，沒變的不動。跳過、reduced-motion、RESET 都只是「立刻套用最終 view」。零件用共用的 builder 做成 three.js 物件（程序幾何、chibi 小人、GLB、煙霧），每個 builder 可帶 `update(dt, t)` 做常駐動畫（吊車、列車、煙、雨）。

**Tech Stack:** three.js r170（vendor/）、node:test、headless Chromium 截圖（`npm run shot`）、CC0 模型（Kenney、Quaternius）。

**Spec:** `docs/superpowers/specs/2026-10-24-grow-taipei-design.md`（§4.1、§5、§7、§9）。引擎事件格式見 `src/rules/engine.js`，規則數值見 `src/rules/spec.js`（本計畫**不改規則**）。

### 舞台介面（Task 4 定義，所有物品模組遵守）

```js
// 物品模組 src/actors/<item>.js
export const id = 'milk';                       // 'tower'、'landmarks' 不是物品，但同樣是模組
export function view(lv, flags) { return { [key]: partSpec, ... }; }   // 純函數；lv = {milk:0..4,...}；flags = {blackout?, flooded?, domeRats?, ratBranch?, bobaSugar?, milkExpired?}
export const builders = { kindName: (THREE, spec, ctx) => Part };     // 可選：模組私有的 kind

// partSpec = { kind: 'compound'|'people'|'glb'|'smoke'|<模組私有>, at: {x,y,z}, ...參數 }
// Part = { object: THREE.Object3D, update?(dt, t), dispose?() }
// ctx = { people, assets, glow, THREE }
```

- partKey 命名 `<模組 id>.<名字>`，例如 `milk.school`、`milk.kids`。
- 兩份 view 的同一個 key 若 `JSON.stringify(spec)` 相同就沿用舊零件；不同就「舊的縮到 0 + 煙 → 新的從 0 彈出」。
- `compound` 的參數：`{ parts: [{ kind, pos:[x,y,z], scale, rot?, color, glow?: hex }] }`，kind 用 kit 的 KINDS；`glow` 有值就用 emissive 材質並登記到 glow registry。
- `people`：`{ n, path?: [{x,y,z}], stand?: [{x,y,z,yaw}], loop?, speed, accessory, shirt?, scale? }`。
- `glb`：`{ path, h, anim?, tint?, glow?, loop?: { path, speed, phase? } }`（loop 讓 GLB 沿路徑移動，面向前進方向）。
- `smoke`：`{ n, size, rise, color?, opacity? }`，在 `at` 上方循環冒煙（spike/v3 的 mkSteam 作法）。

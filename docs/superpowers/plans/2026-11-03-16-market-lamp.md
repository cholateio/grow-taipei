# 夜市跟著燈走、前期電工拿掉 實作計畫（計畫 16）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用者 2026-11-03 截圖：「車站旁的這兩棟是什麼，看不出來」（燈泡的夜市攤子：封閉方塊＋斜屋頂，擺在捷運站旁但跟車站沒有看得出的關係）、「拿掉前期的燈泡工人，他亂跑」。裁決：**A 夜市跟著燈走**——夜市搬到燈泡自己的地盤（中央格第一盞路燈旁），重畫成看得出是攤子的開放式攤位；電工 Lv1–6 不存在，Lv7 才從捷運站走出來搭車去風車島。

**Architecture:** 只動演出層與地標資料：`src/actors/anchors.js`（`LANDMARKS.market` 搬到中央格）、`src/actors/bulb.js`（攤子零件重畫、Lv1–6 劇本沒有電工、Lv2 改成燈光沿環掃過去、電工從 Lv7 起才宣告）、相關測試與截圖。規則層 `src/rules/*` 不動，`npm run check` 仍剛好一解。

**Tech Stack:** 原生 ES modules、three.js（vendor）、`node --test`、無頭演出 `test/helpers/show.js`、`npm run pace`、`npm run shot`、ad hoc 截圖 `node tools/shot.mjs 'name=auto=…&cam=x,y,z,tx,ty,tz'`。

**Spec:** 本檔 §設計；上位設計 `docs/superpowers/specs/2026-10-31-single-path-design.md`（§6 演出、§8 裁決延續到 R33）。

## 設計（決定好的事）

1. **夜市搬到路燈旁**（`anchors.js LANDMARKS.market`）：`{ cell: [0, 0], dx: -1.2, dz: 0.35 }`（世界座標約 (−1.2, 0.35)；第一盞路燈 `ANCHORS.bulb` 在 (−1.3, 1.1)，101 底座西緣 x −0.2、變電所在 (−1.15, −0.85) 0.8 × 0.5）。
   第一攤在地標原點、第二攤東邊 +0.5、往南 +0.15（`marketStalls` 不變）。`MARKET_FRONT`（Lv4 排隊點）改成攤子南邊：`offset(MARKET, 0.25, 0.55)`。
   `MARKET_CELL` 自然變成中央格（`worldToAxial`）。`visitSpot`（老鼠的 trouble 點）照 MARKET 走。
   **走路格驗證**（實作者必做）：攤子外擴 PAD 0.12 後，(a) 中央格西橋頭 (−1.95, 0) ↔ 120° 橋頭 (−0.97, 1.69) ↔ 101 北側之間仍走得通（`nav.route` 不回空），(b) `MARKET_FRONT` 的 `nearestWalkable` 離原點 < 0.15，(c) 既有 `test/helpers/actors.js entryProblems`／`entriesThroughSolutions`、`test/crowd.test.js`、`test/show.test.js` 的 live 整局 `gameInvariants` 全綠。擺不下就把 dx 往西調（最多到 −1.45），不改 dz。
2. **攤子重畫**（`bulb.js stall()`，同一個 compound `bulb.market`，顏色只用現有色票）：
   - 封閉方塊換成**開放式攤位**：四根柱子（`cylinder` 0.03 寬、0.55 高，C.wood）撐一片斜棚（`hip`，屋頂色照舊 coral／yellow，尺寸 0.62 × 0.22 × 0.52）；前面（+z，鏡頭側）一張櫃台（`box` 0.5 × 0.22 × 0.18，C.cream，底在地面）。
   - 櫃台上的東西：第一攤兩層**蒸籠**（兩個疊起來的 `cylinder` 0.16 寬 0.06 高，C.wood，頂上一個白色薄圓蓋 C.white）；第二攤**烤架**（`box` 0.26 × 0.04 × 0.12，C.ink）加三根斜插的竹籤（`cylinder` 0.012 寬 0.2 高，C.cream，rot x 約 −0.5）。
   - **紅燈籠串**：從路燈桿頂（`ANCHORS.bulb` 上方 y 1.0）到第一攤棚頂，等距四顆 `sphere` 0.07（C.coral；Lv3 起 `glowOf(C.coral)` 發光，大停電不亮）；Lv4 第二攤起再加一串到第二攤棚頂。燈籠是 `bulb.market` 的零件（`footprint` 只算攤身，照 `marketFootprint`）。
   - Lv4 的霓虹招牌板留著（純色發光板，不加字），位置改在兩攤棚頂中間上方 `SIGN_AT` 照舊相對座標；Lv9 的 `bulb.neon.market` 招牌跟著 MARKET。
   - draw call：`npm run shot` 的 `wide-end` ≤ 250、手機 ≤ 150；攤子零件顏色種類（含發光）不超過現在的 +2。
3. **電工 Lv1–6 不存在**（`bulb.js view`）：`v['bulb.electrician']` 只在 `n >= ISLAND_LV`（7）宣告，形狀照現在的島上版（`ISLAND_HOME`、`wander`）。`ELECTRICIAN_ENTRY`、`ROAD`（主路巡邏路線）、`LIGHTING_SPEED`、`WALKED`、`lampApproach` 若沒人再用就刪掉（`ROAD` 若只給電工巡邏用就刪；`LAMP_STOPS`、`stopCell` 留給 Lv2 的燈光掃過去）。
4. **劇本沒有電工**（`bulb.js script`，每級 3–4.5 s，◆ 6–8 s）：
   - **放下**：`B.apply(e)`（第一盞路燈自己長出來）→ `B.wait(0.9)` → ♪ 冒在燈頭上（`B.partHead('bulb.main', 0.6, ctx)`，1.0 s）→ `B.wait(1.0)`（同鮮奶放下的節奏）。
   - **Lv2 燈光沿環掃過去**（保留「繞全島一圈」）：從第一盞路燈開始，照 `LAMP_STOPS` 的順序一站一站亮：`B.focus(stopCell(k))`（同一格不重複平移）→ 第 k 站 `B.apply(e, { only: [...(k === 0 ? ['bulb.posts'] : []), 'bulb.lamps.' + k] })` → `B.wait(0.3)`；九站掃完 `B.focus('home')` → 夜市第一攤 `B.apply(e, { only: ['bulb.market'] })` → `B.wait(0.4)` → `B.levelUp('bulb')`。估 4.5–5.5 s（平移拍不算劇本秒數；一級上限 4.5 s 看 pace 的括號數字，超過就把 0.3 改 0.25）。
   - **Lv3 霓虹、傍晚**：`B.focus('home')` → `B.apply(e)`（全島燈頭同一刻換霓虹、燈籠發光）→ `B.wait(0.8)` → `B.world({ time: TIMES.dusk })` → `B.wait(1.2)` → `B.levelUp('bulb')`。
   - **Lv4 第二攤**：照現在（離夜市最近的兩個人快步去排隊、第二攤閃白開張、♥）——`MARKET_CELL` 現在是中央格，`levelUpAtHome` 照舊。
   - **Lv5 全島 LED**：`B.focus('home')` → `B.wait(0.6)` → `B.apply(e)`（LED、101 燈光秀）→ `B.world({ time: TIMES.night })` → `B.wait(1.4)` → `B.levelUp('bulb')`。
   - **Lv6 變電所**：`B.focus(HOME_CELL)` → `B.apply(e)`（變電所長出來）→ `B.wait(0.6)` → ♪ 冒在變電所上（`B.partHead('bulb.substation', 0.7, ctx)`，0.8 s）→ `B.wait(0.6)` → `B.levelUp('bulb')`。
   - **◆ Lv7 電工登場**：有列車時——`B.focus(TOKEN_CELL)` 的同時 `B.apply(e, { only: ['bulb.electrician'], hold: ['bulb.electrician'] })`、`B.spawn('bulb.electrician', c => c.nav.nearestWalkable(frontOf(STATION, 0.9, c.nav)))`（從車站門口走出來；`STATION = anchorWorld('token')`），接著 `board(B, m)` 等現有流程照舊；劇本結尾 `B.home(m)` 讓他留在島上。沒有列車（`!trainLikely(s)`）——`B.apply(e, { only: ['bulb.electrician'], hold: [...] })`、`B.spawn('bulb.electrician', ISLAND_HOME)` 後接現有的 `B.focus(WIND…)`、`B.apply(e)`、`B.home(m)`、`B.focus('home')`、`B.levelUp('bulb')`（`toIsland` 若沒人再用就刪）。
   - Lv8、Lv9 照舊。
5. **測試**（`test/bulb.test.js` 現有 37 處 electrician、`test/roster.test.js` 2 處、`test/satellites.test.js` 1 處、`test/landmarks.test.js`／`test/anchors.test.js` 若有釘 market 座標）：

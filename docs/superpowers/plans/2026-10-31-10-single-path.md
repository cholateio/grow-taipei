# 唯一正解、颱風四站、老鼠當指標 實作計畫（計畫 10）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 規則改成唯一正解 `鮮奶 棒球 代幣 燈泡 晶片 颱風 珍奶 老鼠`（9 回合）；颱風變四站的移動淹水觸發器；珍奶 6 級、老鼠 4 級；外星改壞結局、新壞結局大巨蛋淹水；老鼠聚到出問題的那棟門口。

**Architecture:** 規則資料 `src/rules/spec.js` 整張換成設計附錄；引擎只改「登陸＝颱風放下」（`landsTyphoon`）；`src/rules/endings.js` 飛彈看颱風 < 4、外星壞結局、`domeFlood`；求解器驗「剛好一解」。演出：`src/actors/typhoon.js` 四站（雲用 `B.move` 移站）、`src/actors/baseball.js` 巨蛋淹水零件、`src/actors/boba.js`／`rat.js`／`satellites.js` 級數重切、`src/actors/stage.js` 結算 `meta.trouble`、`rat.js` 的家看 `meta.trouble`。

**Tech Stack:** 原生 ES modules、three.js（vendor）、`node --test`、無頭演出 `test/helpers/show.js`、`npm run check`／`pace`／`shot`。

**Spec:** `docs/superpowers/specs/2026-10-31-single-path-design.md`（§3 逐回合、§4 規則、附錄條件表＝權威、§5 演出、§6 門檻）

## Global Constraints

- 唯一正解 `milk,baseball,token,bulb,chip,typhoon,boba,rat`，全 MAX、ratBranch cyber；`npm run check` 要「全 MAX 剛好 1」。
- 9 回合、`CLOSING_TURNS = 1`、+2 上限、掃描順序：不變。沒有預設跳級。條件表照附錄一字不差。
- 級數：鮮奶 10、晶片 9、燈泡 9、代幣 10、颱風 4、老鼠 4、珍奶 6、棒球 8（合計 60）。
- 沒有文字／泡泡提示（旅程泡泡照舊）。回合上限 60 + 8 × (◆ − 1)；非 ◆ 劇本 ≤ 4.5 s、◆ ≤ 8 s。
- 註解／文件／commit 用台灣用語的繁體中文；`git add <檔案>`；每個任務至少一個 commit；commit 結尾 `Co-Authored-By`（自己的模型名）＋ `Claude-Session: https://claude.ai/code/session_019cBsH8oPNC297jN6re2WUJ`。

## Review Focus

1. 颱風放下那回合：同回合後面的事件照 indoors 規則（只演 apply + LEVEL UP），而第 7、8 回合（雲移站）大家正常走動——Task 2 的 turn／typhoon 測試要分別驗這兩種回合。
2. 淹水／巨蛋淹水發生時被鎖的物品，之後所有依賴它的級都停在等它；撲空指向車站／巨蛋——Task 5 的壞局探針（使用者 10-30 順序、颱風第 2 個）。
3. 老鼠的家隨 `meta.trouble` 換位置時用走的（不閃白、不瞬移）、不穿牆；trouble 從非空變 null 時走回窩——Task 4 的 `gameInvariants` 測試。
4. 珍奶 Lv5 兩島同時出現（分店、旗艦店、小船、無人機、棧橋）不能超過回合上限，也不能讓離島三段的 `tagAlong` 零件漏閃——Task 3 的 boba 劇本預算測試。
5. 外星變壞結局之後，`finale` 的 epilogue 只對 cyber 播；alien 的 missile 結果照一般壞結局（命中／吹歪）走——Task 1 的 finale 測試。

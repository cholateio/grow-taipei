# 台北成長 — 最終章設計：宣告、趕工、飛彈、結局

日期：2026-10-27。主規格 `2026-10-24-grow-taipei-design.md` §8（飛彈、真結局、壞結局）的實作版，加上使用者 2026-10-27 提的問題：
「第 8 個物品放完後，大家只是 LEVEL UP 三回合，然後結局卡就跳出來，建築都好好的」。
演出層的規則沿用 `2026-10-25-show-layer-design.md`（§4 時間軸、§6 畫面語言、§13–15 鏡頭與節奏），物品 v2 的級數與裁決沿用 `2026-10-26-items-v2-design.md`。

## 1. 意圖

一局的最後三回合現在是「蒙太奇」：每個升級只留走路＋LEVEL UP，2 倍速，沒有故事。飛彈從頭到尾沒出現，結局卡直接蓋上來。
最終章要讓最後 40–60 秒有張力與收尾：先宣告飛彈要來，三回合全島趕工，飛彈真的飛過來，三種結果各有一個畫面，然後才是標題卡；兩條真結局各有一段尾聲（主規格 §8.2）。

優先順序照主規格：好玩 > 好看 > 時事梗。全程卡通：飛彈有表情、沒有火與廢墟。

## 2. 目標、非目標、反目標

目標
- 第 8 個物品放完 → **① 宣告**（約 4 秒）→ **② 趕工三回合**（各 ≤ 30 秒，含倒數數字）→ **③ 飛彈**（≤ 10 秒，三種結果）→ **④ 標題卡**（飛彈畫面停 2 秒後出現；真結局先演 ≤ 12 秒的尾聲）。
- 三種飛彈結果都有畫面：矽盾擋下（煙火、歡呼）、颱風吹歪（飛彈插進北投溫泉）、命中（101 彎成 L、全島躺平比讚）。
- 兩條真結局的尾聲：賽博（101 變黑塔＋螢幕、紅色飛天跑車繞 101 停上屋頂、跑馬燈、機器鼠排隊）、外星（石堆島變降落場、三台 UFO、外星生物、101 變母艦、島民三眼、變異鼠戴王冠坐 101 頂）。
- 節奏、人數、draw call 門檻照舊（§10）。跳過、reduced-motion、RESET 照舊規則；標題卡前 2 秒不能跳過（主規格 §4.2）。

非目標（留給計畫 6）
- 其餘壞結局的專屬畫面：鮮奶過期（整島泛黃、牛奶箱長腳）、糖分超標（滾球）、大停電的手機燈、淹水的划船。停電、淹水、鼠災在颱風登陸時已有畫面（計畫 3／3.5），結局卡照舊。
- 結局圖鑑、分享圖、音效。

反目標
- 最終章把一局拉長太多：宣告＋趕工＋飛彈＋尾聲合計比現在的倒數三回合（賽博 51 秒、外星 52.6 秒）多不超過 30 秒——這是目標，不是門檻：pace 印出合計供對照，硬門檻只有各段的上限（§10）；標題卡前的 2 秒不算。超過時先減的是趕工（走路拿掉、人站在原地揮鋤頭），再來是尾聲的停格，最後才是這個數字。
- 趕工回合變成一片走路：每個趕工升級 ≤ 3 秒真實時間。
- 改規則：引擎、求解器、結局判定（`endings.js`）一個數字都不動；飛彈結果照 `endings.missile(state)`。

## 3. 一局的最後怎麼走

```
第 8 回合（放置）演完
  → 倒數 1：① 宣告 + 數字「3」 + 趕工升級（含 ◆ 關鍵劇本）      ≤ 30 s
  → 倒數 2：數字「2」 + 趕工升級                                     ≤ 30 s
  → 倒數 3：數字「1」 + 趕工升級                                     ≤ 30 s
  → 終局回合：③ 飛彈（≤ 10 s）→ 真結局時接 ④ 尾聲（≤ 12 s）        ≤ 22 s
  → 停 2 s（不能跳過）→ 標題卡
```

倒數三回合仍是引擎的 `advance()` 回合（物品照規則長），仍是蒙太奇 2 倍速；變的是每個升級怎麼演（§5）與回合開頭（§4）。
終局回合不是引擎回合：遊戲層把結局算好（`endings.resolve`），合成事件交給演出層（§9）。

## 4. ① 宣告（倒數 1 的開頭）

鏡頭在全景（上一回合最後已經回全景）。

1. 海平面彼端（鏡頭對面那側的遠方，背景山之外）亮起一團紅光（`finale.flare`：發光的球＋一道淡淡的光柱，脈動）。閃白出現。
2. 主島上所有日常中的小人轉頭看向紅光（同矽盾測試那套「全島抬頭」，最多 24 人），頭上一起冒「！」。
3. 101 頭上冒數字泡泡「3」（真實 1.2 秒；倒數 2、3 回合開頭分別是「2」「1」，取代現在每回合都連冒 3、2、1）。
4. 大家放回日常。

紅光整個倒數期間都在，脈動越來越快（倒數 3／2／1 各 1／2／3 Hz）；飛彈發射時熄掉（§6）。
宣告合計約 4 秒真實時間，算在倒數 1 的 30 秒內。

## 5. ② 趕工三回合

感覺是「趕工」不是「備戰」（使用者 2026-10-27 同意提案，沒另外指定；我的取捨 §12）：全島的人拿起鋤頭把每一級蓋出來，而不是演習或躲藏。

每個倒數回合的事件照引擎順序演，鏡頭照 §13.1 跟主線（同一格連續不重複平移；蒙太奇不空拍）。每個 `grow` 事件怎麼演，照下面的優先序：

1. **◆ 關鍵級**（`script.grow[n].key`）：照演完整劇本（裁決 R11 不變）。
2. **跳級的第二級**（`e.jump`）：`[apply, LEVEL UP]`（不變）。
3. **劇本裡有作者標 `keep` 的拍**（颱風登陸躲雨、矽盾測試閃三下、颱風賴著的「……」）：照今天的蒙太奇過濾（只留走路／套用／LEVEL UP／出場／回家／鏡頭＋keep 的拍）。
4. **模組有 `rushSite(n, s)` 且回傳地點**：**趕工**——
   `[walk(hero → frontOf(site, site.r, nav)), gesture(hero, 'build', 1.6, { at: site }), apply(e), levelUp(item), home(hero)]`。
   hero = 離 site 最近、露出來、日常中（mode 'home'）、不坐車、不在進場、在主島走路格上的小人（people walker；老鼠等模型不算）。找不到 hero → `[apply, LEVEL UP]`。
   蒙太奇 2 倍速下一個趕工升級約 2–3 秒真實時間（走路 ≤ 1.5、揮鋤頭 0.8、閃白、LEVEL UP 0.5）。
5. 其他（`rushSite` 回 null 或模組沒寫）：照今天的蒙太奇過濾。

`rushSite(n, s) → { x, y, z, r } | null`：這一級要蓋的東西在主島上的位置與站位半徑（同 `frontOf` 的 r：101 1.1、廠房 1.3、巨蛋 1.6）。六個建築類物品都寫：鮮奶（校舍／大學）、晶片（廠房、園區、總部、變電站；Lv6 電纜在海裡 → null）、燈泡（Lv2–6 路燈／夜市／變電所；Lv8 電纜 → null）、代幣（車站；Lv8 接駁車 → null）、珍奶（攤車／店；Lv5 森林島分店、Lv6 燈塔島旗艦店 → null）、棒球（球場／巨蛋）。老鼠、颱風不寫（沒有東西可蓋）。

`MONTAGE_CAP` 20 → **26 秒**真實時間（倒數 2 今天就 20–21 秒，加趕工會先撞到 20 的上限、把走路全拿掉）：超過的回合照舊拿掉走路（趕工的走路也拿掉，hero 站在原地朝 site 揮鋤頭；揮鋤頭、閃白、LEVEL UP 留著）。回合上限 30 秒不變。

不變：等待圖框、101 跳階（settle）、fx／stall 事件、颱風登陸後 indoors 規則、回合末回全景。

## 6. ③ 飛彈

終局回合的第一個事件 `{ kind: 'missile', outcome }`，`outcome = endings.missile(state)`：`shield`（晶片 Lv9）／`deflect`（晶片沒滿、颱風正好 Lv2）／`hit`（其他）。真實秒數：

1. 回全景停 0.8 秒；紅光熄掉。
2. 飛彈（`finale.missile`）從紅光的位置發射：紅白條紋圓柱、圓頭、三片尾翼、皺眉的臉（兩顆眼睛＋一條眉毛）；長約 1.2、半徑 0.18。沿拋物線飛向 101，2.5 秒；機頭一直朝前進方向。飛到一半全島小人冒「！」。
3. 結果：
   - **shield**：罩子（`tower.shield`）切到 `full`——整個亮起（0.5 秒內從不透明 0.9 回到 0.5 常駐），飛彈撞在罩面上碎成一發煙火（`fireworks` 一發就停的版本），飛彈本體消失。全島小人原地跳＋「♥」。
   - **deflect**：飛彈飛到 101 旁邊被風吹歪（第二段 1.2 秒，邊轉邊掉），機頭朝下插進北投溫泉池，尾巴露在外面斜 30°；池邊冒一下水花（白煙 4 團、短）。泡溫泉的老鼠（老鼠 ≥3 沒搭捷運時本來就在池裡）照泡。全島「？」再「♪」。這是壞結局「颱風擋飛彈」的畫面。
   - **hit**：飛彈撞進 101 中段，101 從中段像吸管一樣彎成 L（上半段轉 90° 往 +x 倒，天線、燈光秀拿掉；飛彈卡在彎角）。終局時 101 一定已完工或點燈（全部 40320 種順序枚舉過：命中時總等級都 ≥ 26），彎 L 只做完工／點燈兩階段的塔身。全島小人躺平、右手比讚（姿勢持續到標題卡）。這是壞結局「矽盾未就緒」的畫面。
4. 回全景停 1 秒。

飛彈的飛行由零件自己演（同矽盾測試、飛天車：`userData.launch({ speed })`），建好時就是演完的樣子——跳過、reduced-motion、截圖直接看到結果。

## 7. ④ 標題卡與真結局尾聲

壞結局與再接再厲：飛彈畫面停 2 秒 → 標題卡（`showEndCard`，不變）。
真結局（8 個全 MAX）：飛彈一定是 shield；接著同一個終局回合裡演尾聲 `{ kind: 'epilogue', ending }`，演完停 2 秒 → 標題卡。

**賽博**（≤ 12 秒）：天黑（已是夜晚，霓虹再亮）→ 101 閃白換成黑色高塔、頂端一面發光螢幕（朝鏡頭）→ 第四台飛天車（紅色，`orbit` 零件；代幣 Lv10 的三台照飛）從海上飛進來繞 101 一圈、停在屋頂（4 秒）→ 螢幕上跑馬燈泡泡「飛天跑車今日抵台，先付清 755 萬」（3 秒）→ 機器鼠軍團閃白出現在屋頂排成一列迎接（同一批 10 隻，站位搬到屋頂；骨架動畫仍 ≤ 12）→ 全景停 1.5 秒。

**外星**（≤ 12 秒）：鏡頭對溫泉格，變異鼠對天揮手＋「！」→ 回全景：石堆島綠光圈閃白變降落場（圈更亮＋三盞落地燈）→ 三台 UFO（一個零件、三個碟）從天上降到降落場（2 秒）→ 三個外星生物閃白出現在 UFO 旁（綠色、三眼、離地漂浮上下晃，程式幾何）→ 101 閃白變母艦（頂端倒扣碟形、底座懸浮離地 1.0、底下一圈綠光）→ 全島小人長出第三隻眼（額頭正中，動作照舊，排隊的照排）→ 變異鼠（戴王冠）閃白坐到 101 頂端＋「♥」→ 全景停 1.5 秒。

標題卡出現時不再硬切夜晚（現在的 `onFinished` 會把時間切到 night）：畫面照演出留下的狀態。

## 8. 畫面語言與素材

- 全部程式幾何（compound）：紅光、飛彈、水花、降落場燈、UFO（沿用老鼠 Lv5 的 `ufo` 零件造型放大）、外星生物、母艦頂、螢幕。不新增 glb；紅色飛天車用 Kenney Space Kit 現有的 speeder（`craft_speederA.glb`，tint 紅）。
- 色票照 `palette.js`：紅光珊瑚 `C.coral` 偏紅、飛彈紅白、綠光 `C.alien`、霓虹藍 `NEON_BLUE`。
- 小人新姿勢（`people.js`）：`lie`（躺平、右手比讚）與第三隻眼（一個 InstancedMesh，alien 時才畫）。由全島效果（`worldEffects` 多一個 `mood: 'normal' | 'lie' | 'alien'`）切換，不是一個個 gesture。
- 文字泡泡：`bubbles` 多一種 `{ text }`（跑馬燈用；字級比符號小、可兩行）。
- ?quality=low：飛天車照舊不畫（orbit 零件在 low 不畫）；UFO 三個碟併成一個 mesh；外星生物畫；**第三隻眼在 low 也畫**（外星結局的笑點就是它；多一個 draw call；平常的兩眼在 low 仍不畫）；其餘照裁決 R18。

## 9. 技術架構

- **合成事件**：遊戲層（`game.js`）在每個倒數回合的事件最前面插 `{ kind: 'countdown', n, flag: { name: 'alarm', value: n } }`（n = 3, 2, 1）；終局回合是 `show.turn([{ kind: 'missile', outcome, flag: { name: 'missile', value: outcome } }, { kind: 'epilogue', ending, flag: { name: 'epilogue', value: ending } }?], { finale: true })`，之後 `await show.hold(2)` 再 `onFinished`。旗標只存在舞台（`stage.flags`），引擎狀態不碰；`foldEvent` 本來就會折 `e.flag`。
- **模組 `src/actors/finale.js`**（id `finale`）：`view(lv, flags)` 依 `flags.alarm／missile／epilogue` 畫紅光、飛彈、水花、UFO、外星生物、紅色飛天車；`script.countdown／missile／epilogue`。其他模組的 view 讀同一組旗標畫自己的東西：`tower.js`（罩子 full、彎成 L、黑塔＋螢幕、母艦）、`satellites.js`（降落場、石堆老鼠離開）、`rat.js`（軍團上屋頂、變異鼠上 101 頂）、`landmarks.js`（飛彈插在池裡由 finale 畫，池水照舊）。
- **`turn.js`**：`countdown／missile／epilogue` 事件的劇本查 `finale` 模組；終局回合（`finale: true`）不加倍速、不扶正零件、不補鏡頭平移（劇本自己管鏡頭），收尾照舊（回日常、全島效果、回全景）。趕工規則（§5）在蒙太奇分支裡。
- **`show.hold(s)`**：播一個 `wait` 拍；期間 `skip()` 不作用（標題卡前 2 秒不能跳過），reduced-motion 時 0 秒；RESET（abort）照樣中止。
- **零件**：`missile`（compound＋自己的飛行時鐘：`launch({ speed })`、建好即終態）、`fireworks` 加 `once`（一發後停）、`orbit` 沿用（紅車 `fly` 一次、`park` 在屋頂、沒有 `rest`）。
- **全島效果**：`worldEffects` 多 `mood`；app 把它交給 `people.setMood(mood)`。

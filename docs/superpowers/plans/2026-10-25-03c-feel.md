# 計畫 3.6 手感 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓玩家看得出「這個變化是誰造成的、發生在哪」，並讓變身動畫有節奏、有份量（錄影審查 2026-10-25 的建議 2–5）。

**Architecture:** 導演改成「從事件開始算時間、沒演東西就不等」；遊戲在每個事件當下回報全島狀態、在回合最後補一個 `settle` 事件；舞台把 101 跳階與「颱風登陸」這兩個回合層級的狀態放在 `meta`，只在 `settle` 更新；全島光線在 app 裡用每幀趨近（約 1 秒）取代一刀切；物品列負責飛入與跳動。

**Tech Stack:** 原生 ES modules、three.js（vendor）、node:test。

**Spec:** `docs/superpowers/specs/2026-10-24-grow-taipei-design.md`（§4.1 物品從框裡飛到島上、§7.1 轉場、§7.2 導演）

## Global Constraints

- 鏡頭不跟事件走（§7.2，使用者 2026-10-25）。
- 畫面上不演光點、轉頭、標籤（§7.2）；飄字只有「圖示 + Lv.n」與 101 的跳階字。
- 跳過、reduced-motion、RESET 一律「立刻套用最終狀態」（§7.1）。
- draw call ≤ 150（§10）；`npm test`、`npm run check`、`npm run shot` 全綠。
- 規則與求解器不動（`src/rules/spec.js`、`src/solver/` 不改）。

## Review Focus

1. 跳過（點畫面）發生在飛入途中或颱風登陸回合中：最後畫面要等於引擎狀態（小人、雨、101 都對）。
2. RESET 在飛入／淡入途中：新局的光線、小人、雨、101 回到開局，舊的飛入圖示不殘留。
3. reduced-motion：沒有飛入、沒有淡入，事件不等待。
4. 一回合內 101 跨兩階（例如 8→20）：只彈一次、飄最終階的字。
5. 颱風 Lv2 被大巨蛋卡住的後續回合：小人在、小孩不躲、雨變小；颱風升 Lv3 後雨與烏雲消失。

### Task 1: 導演從事件開始計時、沒演就不等

**Files:** Modify `src/director.js`; Test `test/director.test.js`

**Interfaces:** Produces `DURATIONS = { placed: 1100, grow: 800, fx: 800, stall: 950, after: 700, settle: 900, wait: 0 }`；`onEvent` 回傳的 promise 若 resolve 成 `false` 表示「畫面上沒演東西」，導演不等。

- [ ] 測試：`timer starts with the event`（`wait` 在 `onEvent` 回來之前就被呼叫）、`an event that shows nothing does not wait`（`wait` 永不 resolve、`onEvent` 回 `false`，`play` 仍完成）、既有測試的 DURATIONS 改新值。看它失敗。
- [ ] 實作：非 instant 且 `DURATIONS[kind] !== 0` 時先 `const timer = wait(ms)`，`await onEvent`，結果不是 `false` 才 `race(timer, skip)`。
- [ ] `npm test` 綠，commit `feat: 導演從事件開始計時，沒演東西的事件不等`。

### Task 2: 事件折疊共用、舞台的 settle 與 meta

**Files:** Modify `src/rules/engine.js`, `src/actors/stage.js`, `src/actors/tower.js`, `src/actors/milk.js`; Test `test/engine.test.js`, `test/stage.test.js`, `test/tower.test.js`, `test/milk.test.js`

**Interfaces:**
- Produces `engine.foldEvent({ lv, flags }, e) → { lv, flags }`（純函數，placed→1、grow→to、delta→to、flag→value；其他原樣回傳）。
- Produces `landsTyphoon(e) → boolean`（`src/rules/engine.js`）：事件把颱風從 <2 變成 2。
- 模組 `view(lv, flags, meta)`，`meta = { total, landing }`。`total` 只在 `settle` 更新成等級總和（開局 0）；`landing` 在 `landsTyphoon(e)` 的事件設 true、`settle` 設 false。
- `tower.view` 用 `meta.total`（沒給就自己加總）；`tower.main` 帶 `labelY = top + 0.6`；`export const STAGE_NAMES = { site: '101 工地', half: '101 蓋一半', full: '101 完工', lit: '101 點燈' }`。
- `milk.view` 的小孩回家條件改 `lv.rat >= 2 || (lv.typhoon === 2 && meta.landing)`。
- `stage.apply(e)` 回傳 `Promise<boolean>`：畫面沒變（wait、扣不動、settle 沒變）resolve `false`。`settle` 若 101 換階，在塔頂飄 `STAGE_NAMES[stage]`。
- 舞台新增 `headOf(id)`、`meta` getter。

- [ ] 測試：`foldEvent` 各種事件；`landsTyphoon`（grow 1→2 true、delta to 2 true、grow 2→3 false）；舞台 `grow events leave 101 alone until settle`（加總跨 9 時 `tower.main` 不變，`settle` 後換成半成品並飄「101 蓋一半」）、`two thresholds in one turn pop once`、`settle with no change resolves false`、`wait resolves false`；`milk kids stay out after the landing turn`。看它們失敗。
- [ ] 實作；舞台 `lv/flags` 改用 `foldEvent`。
- [ ] `npm test` 綠，commit。

### Task 4: 全島效果在事件當下、一秒淡入；颱風只在登陸回合趕人

**Files:** Modify `src/actors/world.js`, `src/actors/typhoon.js`, `src/app.js`; Test `test/world.test.js`（新）、`test/typhoon.test.js`

**Interfaces:**
- `worldEffects(lv, flags, meta = {}) → { time, peopleVisible, glowScale, storm, rain }`：`peopleVisible = !(lv.typhoon === 2 && meta.landing)`；`storm`/`rain` 颱風 Lv2 時登陸 1、賴著 0.35，其他 0。
- `stepWorld(cur, target, dt) → next`：數值欄位以 `1 - exp(-4·dt)` 趨近，差距小於 0.5 分鐘／0.01 就貼齊；`peopleVisible` 直接用目標。
- 雨的 builder 讀 `ctx.weather.rain`（0–1）決定顯示根數與透明度。
- app：`onLevels` → `worldEffects(lv, flags, actors.meta)` 設目標；`instant` 或 restart 時貼齊；每幀 `stepWorld` 後套到 `setTime / people / glow / water / ctx.weather`；結局的夜晚也走淡入。

- [ ] 測試：`worldEffects` 登陸／賴著／Lv3；`stepWorld` 約 1 秒內到 98%、會貼齊、不超過；`rain shows fewer drops when weather.rain is low`。看它們失敗。
- [ ] 實作，`npm test` 綠，commit。

### Task 5: 物品列飛入、跳動；飄字帶圖示

**Files:** Modify `src/ui/slots.js`, `src/ui/ui.css`, `src/actors/stage.js`, `src/app.js`, `test/helpers/fakedom.js`; Test `test/ui.test.js`, `test/stage.test.js`

**Interfaces:**
- `slots.setLevel(id, lv)`：文字真的變了才加 `bump` class（重播動畫）；`reset` 清掉。
- `slots.fly(id, to: {x, y} | null) → Promise`：在 `document.body` 放一個 `.fly` 圖示，從格子中心飛到 `to`（450 ms，Web Animations），結束移除；`to` 為 null 或瀏覽器沒有 `animate` 就立刻 resolve。
- 舞台 `ctx.icons`（`ICONS`）：飄字內層 `<span class="rise">` 裡放 `圖示 + Lv.n`；101 不放圖示。
- app：`ui.fly = id => slots.fly(id, screenOf(actors.headOf(id)))`，`screenOf` 把世界座標投影到螢幕，在畫面外回 null。

- [ ] 測試：fakedom 補 `classList`；`setLevel bumps only on change`、`fly resolves at once without animate`、`floats carry the item icon`。看它們失敗。
- [ ] 實作，`npm test` 綠，commit。

### Task 6: 變身動畫：預備、份量、煙

**Files:** Modify `src/actors/stage.js`; Test `test/stage.test.js`

**Interfaces（數值）:** `ANTICIPATE = 0.15`（舊零件先壓扁：y→0.82、xz→1.1）、`SHRINK = 0.2`、`POP = 0.55`、同一事件多個新零件每個晚 `0.05`（最多 0.3）；替換時新零件晚 `ANTICIPATE` 才彈。零件半徑 r 取建好時的包圍盒；回彈係數 `clamp(2.2 − 0.25·r, 0.15, 1.9)`；煙 `n = clamp(round(3 + 1.2r), 3, 10)`、大小 `min(0.9, 0.15 + 0.12r)`，從包圍盒底部中心冒；純新增與移除都冒煙，替換只冒一次。

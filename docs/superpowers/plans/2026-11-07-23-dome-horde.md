## Global Constraints

- 畫面不加字；泡泡只用「！」「♪」。
- 鼠群只落在巨蛋格 `[-1,1]`、它到 `[0,1]`／`[-1,0]`／`[0,0]` 的三座橋面、鄰格離橋頭 ≤ 0.8——其他地方一隻都不能有（測試釘）。
- 骨架 ≤ 12；鼠群一個 draw call；手機截圖 ≤ 150。
- 收尾 ≤ 5.5 s、鼠災終局 ≤ 16 s；`npm run pace -- --check` 無 ⚠；`npm run check` 一解。

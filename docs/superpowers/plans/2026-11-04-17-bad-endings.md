# 壞結局各自收尾、矽盾未就緒看得出來、變異鼠稱王變災難 實作計畫（計畫 17）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用者 2026-11-04：(1) 87% 的局結尾都是同一個畫面（隕石命中、101 彎掉、躺平），壞結局之間分不出來——每個常見壞結局在隕石之後各演一小段收尾；(2) 「變異鼠王結局再更災難一點，目前只有變異鼠王在溫泉旁戴冠不夠恐怖」；(3) 「矽盾有了，但 101 還是會歪掉？」——查明是晶片 Lv7 天線、Lv8 罩子測試讓玩家以為矽盾在了，規則上只有 Lv9 擋得住；改成警告時罩子試升失敗（看得出沒就緒）。

**Architecture:** 規則層只動 `src/rules/endings.js`（拿掉永遠到不了的 bobaSugar）；`src/game.js finaleEvents` 對有收尾劇本的壞結局也發 `epilogue` 事件；收尾劇本全在 `src/actors/finale.js script.epilogue`（照 `e.ending` 分派），零件在各物品模組（看 `flags.epilogue`）。終局回合（警告＋隕石＋收尾）壞結局上限 12 → 16 s（`tools/pace.mjs BAD_FINALE_MAX`）。

**Tech Stack:** 原生 ES modules、three.js（vendor）、`node --test`、無頭演出 `test/helpers/show.js`（`EXAMPLE` 壞局在 `test/helpers/endings.js`）、`npm run pace`、`npm run shot`。

**Spec:** 本檔 §設計；上位設計 `docs/superpowers/specs/2026-10-27-final-chapter-design.md` §6–§8、`docs/superpowers/specs/2026-10-31-single-path-design.md` §4.5／§8（裁決延續到 R35）。

## 設計（決定好的事）

1. **結局表**（`src/rules/endings.js`）：`bobaSugar` 從 `ENDINGS` 與 `satisfied` 拿掉（全枚舉 40,320 種順序一次都到不了，死規則）；`src/rules/spec.js` 珍奶 `onLevel[4]` 的 `bobaSugar` 旗標一起拿掉（只是旗標，`npm run check` 仍剛好一解）。`test/endings.test.js`、`test/spec.test.js` 跟著改。
2. **終局事件**（`src/game.js finaleEvents`）：`ENDINGS[id].kind === 'true'` 或 `id ∈ BAD_EPILOGUES`（`finale.js` 匯出：`['blackout', 'flood', 'alien', 'domeFlood', 'cartBlown', 'milkExpired']`）就推 `{ kind: 'epilogue', ending: id, flag: { name: 'epilogue', value: id } }`。`shieldDown`、`domeRats`、`typhoonDeflect`、`tryAgain` 沒有收尾。
3. **矽盾未就緒看得出來**（`finale.js script.warning`）：警告拍序照舊，但晶片 7–8（`s.lv.chip` 7 或 8，且不是 shield 結果）時在全島抬頭之後、「！」之前插一段 **試升失敗** `shieldFail`：`tower.shield` 以 `'fail'` 狀態套上（`parts.js shieldPose('fail', t)`：0–0.4 s 升到 0.6 倍大、不透明度 0.35 → 0.5–0.9 s 閃兩下（0.5 ↔ 0.05）→ 1.2 s 縮回 0、藏起來；總長 `SHIELD_FAIL_DUR = 1.3`），同時天線環（`tower.antenna`）閃白一下（`blink.part`）；晶片 ≤6 沒有這段。`tower.js view`：`flags.missile` 還沒設、`lv.chip` 7–8 時 `tower.shield` 由劇本用 `B.replay` 觸發（Lv8 的 `'test'` 狀態照舊；Lv7 本來沒有罩子零件——`shieldSpec('fail')` 只在這段期間套上，演完 `B.apply(e, { only: ['tower.shield'] })` 拿掉）。警告整段 ≤ 5.0 s。
4. **收尾劇本**（`finale.js script.epilogue`，每段 ≤ 7.0 s 真實秒數，終局回合 1 倍速；每段最後 `B.focus('home', { hold: END_HOLD })`；隕石 hit 之後全島是躺平心情 `mood 'lie'`，收尾裡要動的人先 `B.worldNow()` 把心情切回 normal（world.js：`flags.epilogue` 有值就不躺）：
   - **blackout 大停電**（隕石 hit 之後）：`B.world({ time: TIMES.pitch })`（`daynight.js TIMES.pitch = 1380`，比夜晚更黑、天空近黑、環境光 0.15 倍）→ 鏡頭到 101 塔尖（`B.focus` 101 頂、zoom 1.2）→ 警示燈 `finale.beacon` 從慢閃變快閃（零件 `rate` 2 倍，`B.replay`）1.5 s → 回全景停 END_HOLD。整段約 4.5 s。
   - **flood 捷運淹水**：鏡頭到捷運格 → 新零件 `token.floodSheet`（捷運格整格的半透明藍色薄板，`kind: 'compound'` 一個 `box` 0.04 厚、顏色 `C.glass`、不透明度 0.55、`footprint: false`、`shadow: false`）從格面下 `B.move` 升到格面上 0.08（1.0 s）→ 小船 `token.boat`（glb `quat/ships/Boat.glb`，tint 同鮮奶的 `BOAT_TINT`，h 0.35）從車站門口 `B.move` 划到捷運格東南岸（2.5 s），站長（`token.staff` 第一位）和一個 `token.swimmers` 成員用 `B.seat` 式每幀 `setPose` 坐在船上（同燈泡 Lv7 的 `ride` 做法，座位偏移 ±0.15）→ 珍奶老闆 `B.jump` 到攤車屋頂（`boba.owner`，落點 SHOP 上方 0.95）→ 全景停。整段約 5.5 s。
   - **alien 變異鼠稱王（災難版）**：以現有 `alien()` 為底，前面加「鼠群變異」：鏡頭到溫泉格、鼠王 `wave`＋「！」（照舊）→ `B.apply(e, { only: ['rat.pack'] })`：`rat.js` 在 `flags.epilogue === 'alien'` 時 `rat.pack` 改成 **10 隻變異鼠**（tint `C.alien`、glow、三眼 `eye: true`、`antenna: false`），家是 `stand` 在 `ROOF_SPOTS`（101 屋頂，同賽博機器鼠），入口 `PARK_ENTRIES`——牠們從公園入口閃白出現、衝向 101（`roof(rats, …)` 閃白上屋頂，同賽博）；同時全島小人 **躲進建築**（`roster.hide` 全部，同颱風放下的躲雨；收尾最後 `showAll({ walk: true })` 走出來）→ 石堆島綠光圈變降落場、三台 UFO 降落、外星生物上岸（照舊）→ 回全景 → 101 閃白變母艦、鼠王坐上碟頂（照舊）→ `B.world({ mood: 'alien' })` 全島走出來、額頭第三隻眼 → 鼠王「♥」→ 全景停。整段 ≤ 7.0 s（現有 alien() 量到幾秒就砍 `ALIEN_HOLD`／`UFO_FALL`）。`rat.ufo` 小 UFO 照舊不畫。
   - **domeFlood 大巨蛋淹水**：鏡頭到球場格 → 屋頂上第一個球員（`baseball.players` roof spot）`gesture 'knock'`（拉竿）→ 新零件 `baseball.fish`（`compound`：一個橘色 `sphere` 拉長 [0.18, 0.08, 0.08]＋小三角尾鰭，`footprint: false`）從泳池水面 `B.move` 彈出一個拋物線（dy 0 → 0.9 → 0，dx 往球員方向 0.5，0.8 s；`move` 不支援弧線就用兩段）→ 球員「♪」、另一個球員「！」→ 全景停。整段約 4.0 s。
   - **cartBlown 珍奶攤被吹走**：鏡頭到珍奶格東岸 → 小船 `boba.boat`（同一個 Boat.glb）在岸邊出現（閃白）、老闆 `B.jump` 上船 → 船 `B.move` 往攤車划（2.0 s），攤車 `boba.main`（blownCart）同時 `B.move` 往海上漂遠 1.2 m（2.0 s）→ 老闆「！」→ 全景停。整段約 4.5 s。
   - **milkExpired 鮮奶過期**：鏡頭到鮮奶格 → `milk.crate` 換成**過期版**（`milk.js` 看 `flags.epilogue === 'milkExpired'`：箱體 `C.yellow` 偏綠（新色票 `C.sour`：0xb9c45a）、側面兩條腿 `cylinder` 0.05 × 0.3、腳 `box`）閃白 → 兩個小學生 `look` 著箱子、「……」→ 箱子 `B.move` 走到西岸（1.5 s，沿 x 往 −2.4）再 `B.move` 掉進海裡（dy −0.8，0.5 s）、水花 `finale.splash` 挪到那裡 → 全景停。整段約 4.5 s。

## Review Focus

1. **演到一半跳過**（老鼠走到一半、列車進站停著、鏡頭平移到一半、白光閃一半）：最終畫面必須等於引擎狀態——所有零件揭露、名冊人數／配件／位置都在家、鏡頭回全景、`rail.offset` 不再被改、沒有殘留泡泡與白光。
2. **RESET 在任何一拍中間**：名冊清空、舞台重建、小人／模型／發光登記表回開局；舊回合的 Promise 不能碰新局。
3. **尋路起點或終點落在 footprint 裡或水上**（放置後建築蓋在角色腳下；終點是攤車、牛奶箱本身）：要走到邊緣最近的可走點，不能卡住或穿牆。
4. **名冊人數變動與 `hold`／`from` 同一回合疊在一起**（鮮奶 Lv5 小學生換帽又搬家、晶片 Lv3 工程師 2→4 加上偵防師 `from`）：同一個小人不消失再出現，人數對得上 view 的宣告。
5. **列車進站時列車根本不在環上**（代幣 <2 時晶片 Lv5 不會發生，但棒球 Lv4、老鼠 Lv3、代幣 Lv3／Lv6 都要列車）：`trainStop` 在列車不存在時不等待、不卡死。

  ```js
  export const STEP = 0.3, MARGIN = 0.35, BRIDGE_HALF = 0.25, SEPARATION = 0.25;
  export function createNav({ step = STEP, rnd = Math.random } = {})
  nav.walkable(x, z) → boolean           // 六角格內（離邊 ≥ MARGIN）或橋面上，且不在 footprint 裡
  nav.groundY(x, z) → number             // 橋上：兩端 cellTop 線性插值；格內：cellTop；其他：WATER_Y
  nav.setFootprints(list)                // [{ x, z, r }] 或 [{ x, z, w, d }]（軸對齊矩形，w 沿 x、d 沿 z）
  nav.nearestWalkable({ x, z }) → { x, y, z }
  nav.route(from, to) → [{ x, y, z }, …]  // A* 八方向（不切角）+ 視線拉直；起終點不可走就各自改成最近可走點；頭尾是實際起點與修正後終點
  nav.routeLength(path) → number
  nav.slots(center, n, r) → [{ x, y, z }] // 半徑 r 圓上 n 個可走點，彼此 ≥ SEPARATION；不夠就 r += 0.3 再找
  nav.wander(home, r) → { x, y, z }       // home 周圍半徑 r 內隨機可走點（試 12 次，否則 nearestWalkable(home)）
  nav.separate(members, dt)              // 走動中的成員兩兩距離 < SEPARATION 就互推（只改 pos.x/z）
  ```

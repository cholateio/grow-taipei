# 台北成長 演出層重做：旅程式回合

取代主規格 `2026-10-24-grow-taipei-design.md` 的 §4.2 後半、§7 全部；§5.1 的「衍生角色」改由本文件 §8 的劇本定義。規則引擎（§6）、求解器、結局判定不動。

依據：`docs/research/2026-10-25-grow-island-video-analysis.md`（GROW Island／Cube／Valley 影片分析）、老鼠回合試作 `?spike=rat`（使用者 2026-10-25 看過後確認方向）。

## 1. 意圖

玩家要看得出**這個變化是誰造成的、發生在哪**，而且看著舒服。GROW 系列做到這點靠的不是轉場動畫，而是：一回合一條主線、角色走過去、結果在它停下的地方出現、用泡泡表達心情、每次升級留下一個會動的東西。現在的做法（每格各自原地縮放彈出、飄 Lv.n）治不好，所以重做。

## 2. 目標、非目標

目標
- 一回合是一段 15–40 秒的小故事，越後面越長（使用者 2026-10-25 選定）。
- 任何時候畫面上只有一個主角在「演」，其他角色在做自己的日常動作。
- 角色不穿牆、不疊在一起（使用者 2026-10-25：「老鼠都穿牆了」）。
- 鏡頭拉近，主島撐滿畫面，角色和泡泡看得清楚（使用者選定）。
- 跳過、reduced-motion、RESET 一律立刻到最終狀態。

非目標
- 不改規則、不改正解。引擎事件照舊，演出層只決定「怎麼演」。
- 不做語音、不做字幕；泡泡只有符號和圖，沒有文字（「LEVEL UP」除外）。
- 不做自由鏡頭追角色；鏡頭只在換場景時平移。

反目標
- 畫面同時有兩處在閃、在長（看不出主線）。
- 東西從地上縮放彈出（已證明「說不出來的怪」）。
- 角色放大到和建築比例失真。

## 3. 名詞

- **回合**：引擎 `place`／`advance` 吐出的事件列表（placed、grow、fx、stall、wait、settle）。
- **拍（beat）**：演出的最小單位，一個動作加上它的時間。例如「老鼠走到牛奶箱」「老鼠冒 ♥ 1.5 秒」「鮮奶箱白光出現」「LEVEL UP」。
- **劇本（script）**：把一個事件變成一串拍的函數。每個物品模組為自己的 placed、每一級 grow、每個反應各寫一個劇本。沒寫的事件用預設劇本（§6.6）。
- **主角（hero）**：這一拍在動的角色。一回合裡主角可以換人（老鼠演完換站務員），但同一時間只有一個。
- **名冊（roster）**：島上有身分、會跨回合存在的角色（小學生、工程師、老鼠、球員……），§5。
- **時間軸（timeline）**：導演把一回合所有劇本的拍串起來、依序播放的東西（§4）。

## 4. 導演：時間軸

### 4.1 一回合怎麼播

1. 遊戲把這回合的事件交給導演。
2. 導演依引擎的順序，把每個事件交給該物品的劇本，得到一串拍；所有拍接成一條時間軸（事件之間不重疊）。`wait` 事件只有回合最後一個會演（§6.5）；`settle` 是 101 的劇本（§8.9）。
3. 依序播放。每一拍播完才播下一拍，走路的時間就是節奏，拍與拍之間不另外停頓。
4. 全部播完 → 物品列解鎖。

### 4.2 拍的種類

| 拍 | 意思 | 時間 |
|---|---|---|
| `spawn(actor, at)` | 名冊角色出現在某處（白光） | 0.5 s |
| `walk(actor, to)` | 走到某點，走尋路算出的路線（§5.3） | 路長 ÷ 速度（小人 1.6、老鼠 2.0、機車 3.0 單位/秒） |
| `bubble(actor, kind, dur)` | 頭上冒泡泡（§6.1） | 0.8–1.5 s |
| `gesture(actor, kind, dur)` | 小動作：敲、看、揮手、聞、跳（§6.3） | 0.6–1.5 s |
| `apply(event, {flash})` | 把引擎事件套到舞台：view 重算、變化的零件白光出現（§6.4）（已改為 `{blink}` 材質閃白 0.15 s，見 §13.2／13.7） | 0.5 s |
| `levelUp(target)` | 「LEVEL UP」字在目標頭上（§6.2）；掉級是「LEVEL DOWN」灰字 | 1.0 s |
| `camera(target \| 'home')` | 鏡頭平移到衛星島或回主島（§7）（已刪除，由 `focus` 取代，見 §13.1／13.7） | 1.0 s |
| `world(effects)` | 天色、雨、浪的目標值（沿用現在的 1 秒淡入） | 0 |
| `wait(s)` | 單純停 | s |
| `together([...])` | 幾個拍同時播（一群小孩一起跑），時間取最長 | — |
| `home(actor)` | 角色回到日常動作（§5.4），不等它走到 | 0 |

### 4.3 跳過、reduced-motion、RESET

- 點畫面＝跳過：時間軸直接跳到最後。所有還沒套用的事件立刻套用、角色瞬間回到日常位置、鏡頭回主島、泡泡與字清掉。不能跳過結局標題卡前 2 秒（沿用）。
- reduced-motion：每回合等於「立刻跳過」。
- RESET：時間軸中止，名冊清空，舞台重建。

### 4.4 長度預算

- 目標：第 1 回合約 10–15 秒，中段 20–30 秒，後段 30–40 秒。
- 每個拍的時間由劇本決定；`tools/pace.mjs` 把兩條正解每回合的拍時間加總（走路用尋路估算），印出每回合秒數，超過 50 秒或低於 8 秒、倒數回合超過 22 秒就警告（原本 45／20，鏡頭跟主線後改，見 §13.6）。這是驗收的一部分（像 `npm run check`）。
- 倒數三回合（飛彈前的 advance 回合）用**蒙太奇**，這份計畫就做：每個 grow 只演「主角走到目標（兩倍速）+ apply + LEVEL UP」，一回合上限 20 秒，超過就把走路省掉只留 apply + LEVEL UP；回合開始 101 頭上冒「3」「2」「1」泡泡。`pace` 也驗這三回合。飛彈本身留給計畫 4。

## 5. 角色系統

### 5.1 誰是角色

使用者 2026-10-25 決定：**只有部分物品有代表角色，其他是場景變化**；代表角色不一定一開始就在，可以是升級時「走出來的人」。

| 角色 | 來自 | 身分配件 | 日常動作 |
|---|---|---|---|
| 島民 ×6 | 開局 | 無／黃帽 | 沿主路來回 |
| 工人 | 晶片 Lv1 | 安全帽 | 繞工地 |
| 工程師 ×2 → ×4 | 晶片 Lv2／Lv3 | 白袍識別證 → YouBike | 廠門 ↔ 101 通勤 |
| 偵防師 | 晶片 ≥3 且老鼠 ≥2 | 放大鏡 | 跟著老鼠路線 |
| 小學生 ×3 | 鮮奶 Lv2 | 無 → 棒球帽（Lv5）→ 學士帽（Lv6） | 繞操場；Lv5 起在巨蛋旁練球 |
| 電工 | 燈泡 Lv1 | 安全帽＋黃背心（新配件） | 沿有路燈的路巡 |
| 站務員 | 代幣 Lv1 | 深藍制服帽（新配件） | 站門口站著，列車進站時揮手 |
| 老鼠 ×1 → ×5 → ×10 | 老鼠 | 模型；機器鼠加天線、變異鼠放大發綠光 | 窩旁晃／車頂／溫泉 |
| 攤車老闆 | 珍奶 Lv1 | 圍裙（新配件） | 攤車後站著搖杯 |
| 觀光客 ×6 → ×10 | 珍奶 Lv2／Lv3 | 行李箱 | 排隊 |
| 外送機車 | 颱風 Lv2 且珍奶 | 現有 | 繞中心格 |
| 球員 ×2 | 棒球 Lv2 | 棒球帽 | 傳接球 |
| 觀眾 ×4 → ×6 | 棒球 Lv4／Lv5 | 彩色衣 | 巨蛋門口站著，偶爾跳 |
| 工作人員 ×2 | 鼠災 | 安全帽 | 追老鼠 |
| 颱風雲 | 颱風 | 不是人，但是主角：會移動、會冒泡泡 | 島上空飄 |
| 列車、接駁車、船 | 代幣、珍奶 | — | 繞行 |

### 5.2 名冊是持久的

角色由 view 宣告（`{ kind: 'roster', id: 'milk.kids', n: 3, accessory, home }`），但舞台**不重建**同一個 id 的角色：n 變多就補人、配件變了就原地白光換、`home` 變了就走過去（劇本沒走的話）。這樣小學生從小學跑到巨蛋旁是「同一群人」走過去，不是消失再出現。

- **換身分**：宣告可以寫 `from: 'chip.engineers'`，表示這個名冊的人是從另一個名冊「轉過來」的（工程師變偵防師、小學生變通勤的大學生、站務員變泳客）。轉移時原名冊少一人、新名冊多一人，同一個小人原地白光換配件，不消失。
- **人數變少**沒有 `from` 時，多出來的人白光消失。
- **劇本接手出場**：`apply` 可以帶 `hold: ['milk.kids']`，這些名冊先不補人，由劇本用 `spawn` 在它要的位置（校門口、車上）補，補完才交回名冊。

### 5.3 尋路與避讓

- 主島鋪一張 0.3 單位的走路格：六角格內、橋面上可走；每個零件可宣告 `footprint`（相對 at 的圓或矩形），沒宣告的 compound 用包圍盒投影縮 0.9。走路格扣掉 footprint。
- `walk` 用 A*（八方向）＋拉直（視線可達就直走），路線貼地（`groundAt`）。目標落在 footprint 裡就改走到它邊緣最近的可走點。
- 站定點：`slots(center, n, r)` 在半徑 r 的圓上取 n 個可走的點，每人一個，不重疊。
- 走動中的角色之間有 0.25 的推開力（簡單分離），不會疊成一坨。
- 車頂座位：3 節 5 個座位（前、後、前、後、中）、5 節每節一個。
- 日常繞圈的路線也要在走路格上：改成「在 home 周圍可走的格子裡隨機挑下一個點走過去」（不再用固定半徑的圓）。

### 5.4 日常動作

不在演的角色一直在做日常動作（§5.1 表），這就是「每次升級留下一個會動的東西」。演完一拍，主角 `home()` 回日常。

## 6. 畫面語言

### 6.1 泡泡

白底圓角框，角色頭上，隨角色移動。只有這幾種：
- `！` 注意到、`……` 思考或等待、`♥` 滿意或互動成功、`♪` 開心或熱鬧、`？` 困惑。
- **圖框**：框裡放一個圖示（§UI 的八個物品圖示，或少數新畫的：巨蛋、校舍、學士帽、小島、列車、燈）。意思是「他想要這個」，這是解謎的線索（§6.5）。

使用者 2026-10-25：「我喜歡用一點冒泡框表達」。一次只一個角色有泡泡（群體時用 `together`，但同一種）。

### 6.2 LEVEL UP

黃字、墨色描邊、26px，在被升級的東西頭上停 1 秒，往上飄一點淡出。只標被升級的東西；放置不標。掉級：灰字「LEVEL DOWN」往下掉。物品列那格不跳，只在回合結束靜靜寫上 Lv.n（§4.3 的回饋保留；GROW 是到結局才亮，這是我的取捨：解謎線索比純正更重要）。

### 6.3 小動作

沿用小人系統的姿勢：敲（上半身前傾兩下）、看（轉頭向目標）、揮手（手臂上舉擺動）、跳（上下 0.1）；老鼠：聞（轉頭左右）、跳（拋物線上車頂）；颱風雲：鼓脹一下。

### 6.4 出現與消失

出現：該處白光一閃 0.5 秒，東西在閃到最亮時已經在那裡；沒有縮放。消失：同樣白光，閃到最亮時已經不見。`apply` 對 view diff 裡每個變化的零件各做一次白光，但同一拍裡的多個零件**依序**閃（間隔 0.15 秒），不同時。

`apply` 可以分段：`apply(event, { only: ['bulb.lamps.3'] })` 只套用 view diff 裡指定的零件，其餘留給後面的拍（大停電路燈一盞盞熄、屋頂依序換色都靠這個；要依序的東西要拆成一個零件一個鍵）。一個事件的所有零件在該事件的劇本結束前一定全部套用完（劇本末尾自動補套用剩下的）。

全島效果（天色、雨、浪、發光）不再由 `game.js` 在事件當下設定，而是由劇本的 `world` 拍設定；預設劇本在 `apply` 後自動補一個 `world`。跳過時直接貼齊引擎狀態。

### 6.5 等待提示

回合最後，若引擎有 `wait` 事件，挑第一個等待中的物品：它的代表角色（沒有就最近的島民）冒一個**圖框**，裡面是它在等的幫手的物品圖示，1.2 秒（原 1.5，節奏驗收改短，§12）。一回合最多一個。這取代之前拿掉的光點與轉頭：安靜、有故事、有線索。

### 6.6 預設劇本

沒有劇本的事件：`apply(flash)` → `levelUp`。所有事件都能演，劇本是加分不是必要。

## 7. 鏡頭

- 全景拉近：主島七格佔畫面寬約八成，衛星島只露邊。桌機 overview 距離約 19（現在 27），手機直式約 40（現在 56）。拖曳、縮放限制沿用。
- 平移：只在拍 `camera(target)` 時，1 秒 easeInOut 平移到目標（衛星島或 101 頂），鏡頭角度不變；該段拍結束 `camera('home')` 回全景。玩家拖曳會取消平移並回全景。
- 一局裡會平移的只有：代幣 Lv4／Lv5（燈塔島）、珍奶 Lv4（小森林島）、結局飛彈。

## 8. 劇本

格式：**主角**；拍的順序；（預估秒數）。走路秒數依現在的錨點距離估。反應（onLevel）的劇本寫在造成它的物品底下。所有劇本都以 `levelUp` 結尾（placed 除外）。

### 8.1 鮮奶（場景為主；小學生是走出來的人）

- placed：最近的島民走到牛奶箱位置 → 白光牛奶箱 → 島民 `♥` → home。（5 s）
- Lv2 小學：牛奶箱旁白光校舍 → 3 個小學生從校門跑出來到操場 → 日常：繞操場。（5 s）
- Lv3 長高：小學生 `together` 走到牛奶箱 → 各 `♥` → 白光：變高 1.3、校舍加一層 → 跑回操場。（7 s）
- Lv4 三層升旗：一個小學生走到旗桿 → `！` → 旗子升上去（零件 scale.y 0→1，1 s）→ 校舍白光加層。（6 s）
- Lv5 鐘塔、少棒（需棒球 ≥2）：小學生白光換棒球帽 → `together` 走到巨蛋旁空地（約 4 s）→ 球員 `♪` → 鐘塔白光出現 → 小學生日常改成在空地練球。（9 s）
  （節奏驗收：先走到巨蛋東側門前停下、跳起來與球員 `♪` 同一拍；繞到西南空地的最後一段交給日常。實測約 7 s）
- Lv6 大學（需晶片 ≥3）：一個工程師從園區走到校門口 → `……` → 圖框「學士帽」→ 白光：拱門、校舍拉長、小學生換學士帽 → 一個學生跟工程師走回園區（之後日常加入通勤）。（12 s）
- 被老鼠咬（老鼠 Lv2 反應）：見 8.6。
- 颱風假：見 8.5。
- 小學生躲回校舍（窗亮）只在兩種回合：被老鼠咬的那回合（`meta.bitten`）、颱風登陸那回合；下一回合照常出來（建造時的裁定）。
- 大停電冰箱壞：牛奶箱白光變灰 → `LEVEL DOWN`。（2 s，在颱風劇本裡）
- 等待圖框：Lv5 等棒球 → 小學生圖框「棒球」；Lv6 等晶片 → 圖框「晶片」。

### 8.2 晶片（工人 → 工程師）

- placed：白光工地圍籬 → 工人從 101 工地走過來（約 3 s）戴安全帽 → 日常：繞工地。（5 s）
- Lv2 廠房：工人 `……` → 敲 ×2 → 白光廠房、煙囪冒煙 → 2 個工程師從門口走出去 101（日常通勤開始）。（6 s）
- Lv3 園區：工程師騎 YouBike 回來 → `♪` → 白光三棟玻璃盒、招牌 → 4 人通勤。（6 s）
- Lv4 總部（需鮮奶 ≥3）：一個長高的小學生走到園區門口（約 4 s）→ 圖框「晶片」→ 工程師 `♥` → 白光總部。（9 s）
- Lv5 天線（需代幣 ≥3）：列車進站停下（§8.4 的停站機制）→ 工程師走到站前接一個箱子（gesture 敲）→ 走到 101 腳下（約 3 s）→ 101 頂白光天線。（10 s）

### 8.3 燈泡（電工）

- placed：電工從 101 工地走到路邊 → 敲 → 白光路燈 → 日常：在路燈旁巡。（5 s）
- Lv2 整條路：電工沿主路走一圈（約 8 s），每經過一個路燈位置就白光一盞亮起（像 GROW 工人挖路）→ 夜市 2 攤白光。（10 s）
  （建造時的裁定：路燈依路口分成 9 組燈頭零件 `bulb.lamps.0–8`，燈桿全部一個零件 `bulb.posts`；電工從離他最近的那一站沿路繞一圈、一站站點亮，點燈這段快走 2.4 → 節奏驗收改 2.8；夜市兩攤與燈塔島的燈在走最後一段時亮。實測 15–17.5 s）

## 13. 第一輪遊玩後的修正（2026-10-26，使用者錄影審查）

使用者看完整局錄影（`螢幕錄製 2026-10-26 040559.mp4`，3838×1794）的結論：場景太複雜、演出不明顯、看右邊時左邊已經演完、角色仍有重疊與瞬移。分析見對話紀錄；這一節是修正的設計，取代 §4.3、§6.4、§7 的對應段落。

### 13.1 鏡頭跟著主線走（取代 §7「只在換場景時平移」）

- 每個事件的劇本開始前，鏡頭平移＋拉近到這個事件發生的格子（1 秒 easeInOut），拉近到全景距離的 0.6 倍；事件演完換下一個事件時再平移；同一格連續的事件不重複移動；回合最後回全景。
- 劇本可以自己下 `focus` 拍（主角移動到別格時跟過去，例如電工繞路點燈、老鼠跑去捷運站）。
- 不同物品的事件之間空 0.6 秒，鏡頭平移本身就是「換場」。
- 跳過、reduced-motion → 立刻回全景。玩家拖曳鏡頭 → 這回合不再平移，回合結束回全景。
- 原因：鏡頭不指路，觀眾就不知道要看哪裡；島在超寬螢幕上只占三分之一寬，拉近才看得到小人與泡泡。

### 13.2 拿掉平面白光（取代 §6.4）

實作中的裁定與審查修正（照 13.1–13.6 的精神補細節）：

- **focus 拍佔 0.8 秒**，鏡頭照樣飛 1 秒（easeInOut 在 0.8 秒已走完 97%，劇本先接著演）；`focus('home')` 不佔時間。照字面 1 秒＋1 秒會讓最長回合到 52 s。
- **拖過鏡頭**：回合中途的 `focus('home')`（全島的事）也尊重拖過的記號，鏡頭不動；只有回合最後那拍回全景不管拖過沒、並清掉記號。回合開始也放開記號——回合之間拖一下不影響下一回合跟主線。
- **視窗縮放 `fit()` 保留目前框景**（全景或 focus 的目標＋倍率，飛行中就用終點），不再一縮放就跳回全景。
- **零件閃白的順序**：同一個鍵換新（舊＋新）時舊的立刻拿掉、新的閃白；只有新增時新的閃白；只有移除時舊的閃白 0.15 秒後才拿掉（兩個疊在同一處一起閃會打架）。
- **退場用走的**：要離開的名冊成員走回自己的入口點、到了才拿掉（跳過／RESET 立刻拿掉）；在原地消失看起來就是瞬移。
- **走路速度**：進場、退場、搬家用走路速度（小人 1.6、老鼠 2.0）；閒晃保留 0.5（進場若用 0.5 要 3 秒以上）。
- **退場途中又補人**：直接把正在走出去的人叫回來，不另生一個，免得兩人在入口交錯。
- **path 成員（巡路的人）算不算在焦點**：路線經過的任何一格是焦點格就算，不然會在焦點格邊界停住擠成一團。
- **劇本秒數（各物品測試的預算）不含 focus 拍**：測試 helper 的 `run()` 扣掉平移時間，平移是回合層加的；`tools/pace.mjs` 看整回合（`show.elapsed`）。
- **劇本秒數下限調低到實測值**（apply 0.5 → 0.15、spawn 0.5 → 0）：下限是防空劇本，不是控制節奏；之後走路進場又把時間拉回來。
- **人龍間距 0.25**（原 0.22）：站著也套 0.25 分離，間距太小會被推開變形。
- **燈泡放置的劇本下限 3 → 2.5 s**：101 旁可走的站位離第一盞燈較近（實測 2.8 s）。
- **入口點與鏡頭的個別位置**（入口離站位 ≥ 1.5、走得到；每個物品的測試都驗）：代幣站務員從站體北側進來、避開珍奶人龍；珍奶觀光客的碼頭在珍奶格東角、夜市北邊（東邊那條海岸被人龍與夜市擋住，取最近的可走點）；第一隻老鼠從巨蛋格東南外的海裡爬上岸再沿岸繞回窩；賽博 Lv5 補的機器鼠從園區門口出來；颱風雲 focus 抬高到 y 2.6、倍率 0.8；代幣 Lv4／5、珍奶 Lv4 的衛星小島用 focus（倍率 0.8）取代舊的平移拍，舊的 `camera` 拍已刪除。
- **回全景飛到一半被點一下**（final review）：最後那拍 `focus('home')` 不佔時間，`turn()` resolve 時鏡頭還在飛回全景；這時按下滑鼠（`cancel()`）直接落在全景、照樣標記拖過，不停在半路。其他框景（focus、平移）被點照舊停在原地。不拉長最後那拍（節奏餘裕只剩 1.1 s）。
- **焦點外也不疊著**（final review）：休息中的 wander 成員、焦點外停下的 path 成員離任何露出來的成員 < 0.25 就不停——wander 馬上走下一趟、path 沿路接著走，走開了才停（用走的，不滑）。只有站定的 stand 成員用 `separateStanding` 沿 x 滑開。
- **日常的人不瞬移**（final review）：`nav.separate` 每幀從游標重算推擠，一串人互推、或有人開始／停下走路時推擠突然出現／消失，path 成員會一幀閃 0.3–0.55。改成名冊每幀限制日常、退場中的人的位移 ≤ 自己的走路速度 × dt（小人 1.6、老鼠 2.0），推擠變成滑過去；劇本手上的人、ride、藏起來的人不限。代價：沿線來回交會的 path 成員不再被一幀推開，交會時會短暫靠近（實測同一對在 0.25 內最多 0.13 s）。
- **寬螢幕截圖**：`npm run shot` 加 `wide`（2560×1080 結局全景）與 `wide-live`（第 6 回合鮮奶放下那一刻，鏡頭拉近在鮮奶格、泡泡看得清楚）；有 live 的 wide 截圖虛擬時間只給 1.5 s，不然 warp 之後動畫還會繼續演到回合結束、鏡頭已回全景。draw call 最多 138（≤ 150）。
